Title: Can LLM-Based Synthetic Users Simulate Customer Behavior and Predict A/B Test Outcomes?

Authors: Egor Lozovoi

Primary category: cs.AI
Cross-list: stat.AP

Comments: 4 figures; reproducibility: 398 exact statistics, 693 counts, 102 values require closed per-test data

Abstract (1845 characters, limit 1920):
Can LLM-based synthetic users simulate shoppers and predict interface A/B test outcomes? We test this on 47 internal, unpublished experiments of a grocery retailer (18 "+", 22 "0", 7 "-") and a blind held-out set of 25 comparisons whose inputs were initially assembled by an agent without access to outcomes. Each agent receives a purchase-derived profile and visit goal, sees one variant on phone screenshots, and navigates the app; action frequencies are checked against held-out human data, with set compositions and success thresholds recorded before the runs. The answer is twofold: shopper behavior could be simulated only partly, and simulation forecasts did not beat simple baselines--a direct forecast from the test description and "always zero". On Summary-27, the simulator is right in 14-17 cases versus 13 for a direct forecast by the same model, 16 for the strongest model, and 13 for "always zero" (exact McNemar, p >= 0.289). A frozen version scores 20/36 (vs. 20 and 16) and 10/25 on the blind set (vs. 15 and 12). Rank association with the real effect is unstable and fragile: on the main rank set (n = 33), $\rho$ ranges from -0.08 to +0.19; on the blind set it is +0.39 for clicks (n = 24), dropping to +0.30 (p = 0.079) without the single largest effect. Ten improvement hypotheses gave no stable gain. Behavioral calibration moved product comparison into the pre-recorded human tolerance band (18% to 36% of sessions) without establishing transfer to A/B accuracy, and the human response to a photo change was not reproduced in any of three tests. In the binary metric of related work the simulator looks successful (9-10 of 14), but "always +" gives the same. Without null tests, a direct forecast, and a replication, such evaluation overstates simulation value. Tests remain closed; code and aggregate data are on GitHub.
